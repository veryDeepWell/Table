# За столом

Каталог настольных игр на русском языке: го, шахматы, русские шашки, короткие нарды, сёги, «Точки», «4 в ряд» и маджонг. У всех игр есть сетевой режим и правила с примерами.

## Запуск

Нужен Node.js 22+.

```sh
npm run dev
npm test
npm run build
```

Локальный адрес: http://127.0.0.1:5173. Сборка в `dist/`.

## Сервер комнат

На компьютере, который будет хостить комнаты, нужны Node.js 22+ и cloudflared. Маршрут именованного туннеля для `https://table-games.lol` должен вести на `http://127.0.0.1:5173`.

1. В каталоге проекта запустите `npm.cmd run dev` в PowerShell.
2. Запустите тот же именованный туннель через `cloudflared tunnel run --token "<токен>"` или оставьте его запущенным как службу Windows. Храните токен у себя. Для этого адреса используйте один активный компьютер.
3. Откройте игру на GitHub Pages и разверните **Играть по сети**. Создайте комнату с именем и паролем, выберите сторону или случайную рассадку.
4. Передайте друзьям имя и пароль либо ссылку на вход и пароль. Партия начнётся, когда все места заняты.

Хостить сервер и создавать игровую комнату могут разные люди. В шапке сайта видно, отвечает ли сервер. Локальная версия сайта обращается к серверу, с которого открыта. Для другого адреса GitHub Pages задайте `TABLE_ORIGIN` с origin сайта без имени репозитория. Постоянный адрес сервера для опубликованного сайта задаётся в `src/online/server.js`.

Комнаты хранятся в памяти и закрываются при перезапуске сервера или после 30 минут без запросов игроков. Перезагрузка страницы в той же вкладке сохраняет место. Во время партии выход засчитывает поражение, при потере связи у игрока есть 20 секунд, чтобы вернуться. В играх со скрытой информацией браузер получает только данные своего места и открытые данные стола.

## GitHub Pages

В настройках репозитория выберите **Pages → Source → GitHub Actions**. После отправки в `main` workflow `.github/workflows/pages.yml` проверит движок, соберёт сайт и опубликует Pages. Если основная ветка называется иначе, измените `branches` в workflow. Все пути относительные, маршруты используют hash: сайт работает и в подпапке репозитория. Публикация из текущей рабочей копии не выполнялась.

## Архитектура

- `src/app.js` — общая оболочка, каталог и маршрутизация.
- `src/data/games.js` — реестр игр и ленивые загрузчики модулей.
- `src/games/<id>/engine.js` — чистые функции игровой логики, без DOM.
- `src/games/<id>/view.js` — интерфейс и правила игры.
- `src/online/` — запуск и подключение к комнатам, профиль и чат.
- `server/match.mjs` — общий протокол комнаты, `server/match-games.mjs` — адаптеры игровых движков.
- `src/games/table-view.js` — общая оболочка для шахмат, шашек, нард и сёги с подсветкой ходов, отменой действий и сохранением.
- `src/style.css` — адаптивное оформление и общие компоненты.
- `tests/` — проверки игровых правил средствами Node.js.

Для новой игры добавьте каталог `src/games/<id>/`, экспортируйте `render(root)` из модуля интерфейса и зарегистрируйте игру в `games.js`. Карточки и поиск строятся из реестра. Движки не зависят от интерфейса и хранилища.

## Правила и ограничения

В го используются китайский подсчёт площади, коми 7,5, запрет самоубийства и позиционное суперко. Два паса завершают партию. Мёртвые группы автоматически не определяются: спорные позиции нужно доиграть через «Продолжить игру». Счёт берётся по текущей доске.

Правила сверены с материалами [British Go Association](https://www.britgo.org/intro/intro2.html) и [сравнением систем правил](https://www.britgo.org/rules/compare.html). Google Fonts необязательны: при отсутствии сети используется системный шрифт. Позиция хранится только в localStorage браузера.
