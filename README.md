# За столом

Статический каталог настольных игр на русском языке. Первая игра — го: локальная партия на двоих, доски 9/13/19, сохранение в браузере, правила с диаграммами. Без зависимостей и серверной части.

## Запуск

Нужен Node.js 22+.

```sh
npm run dev
npm test
npm run build
```

Локальный адрес: http://127.0.0.1:5173. Сборка в `dist/`.

## GitHub Pages

В настройках репозитория выберите **Pages → Source → GitHub Actions**. После отправки в `main` workflow `.github/workflows/pages.yml` проверит движок, соберёт сайт и опубликует Pages. Если основная ветка называется иначе, измените `branches` в workflow. Все пути относительные, маршруты используют hash: сайт работает и в подпапке репозитория. Публикация из текущей рабочей копии не выполнялась.

## Архитектура

- `src/app.js` — общая оболочка, каталог и маршрутизация.
- `src/data/games.js` — реестр игр и ленивые загрузчики модулей.
- `src/games/go/engine.js` — чистые функции игровой логики, без DOM.
- `src/games/go/view.js` — интерфейс, правила и локальное сохранение.
- `src/style.css` — адаптивное оформление и общие компоненты.
- `tests/` — проверки игровых правил средствами Node.js.

Для новой игры добавьте каталог `src/games/<id>/`, экспортируйте `render(root)` из модуля интерфейса и зарегистрируйте игру в `games.js`. Карточки и поиск строятся из реестра; для новых игр добавьте собственное оформление обложек и при необходимости расширьте фильтры. Движки не должны зависеть от интерфейса и хранилища: это позволит добавить сетевые матчи или ИИ отдельно.

## Правила и ограничения

Используются китайский подсчёт площади, коми 7,5, запрет самоубийства и позиционное суперко. Два паса завершают партию. Мёртвые группы автоматически не определяются: спорные позиции нужно доиграть через «Продолжить игру». Счёт берётся по текущей доске. Онлайн-мультиплеера и компьютерного соперника пока нет.

Правила сверены с материалами [British Go Association](https://www.britgo.org/intro/intro2.html) и [сравнением систем правил](https://www.britgo.org/rules/compare.html). Google Fonts необязательны: при отсутствии сети используется системный шрифт. Позиция хранится только в localStorage браузера.
